# Auro8 Extensions

> A custom extension repository for Mihon and compatible apps.

## Adding the Repo

1. Open Mihon
2. Go to **More → Settings → Browse → Extension repos**
3. Tap **+** and paste this URL:
https://raw.githubusercontent.com/Auro8/my-extensions/repo/index.min.json



## Available Extensions
